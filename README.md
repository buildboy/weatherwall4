# Weather Wall

Full-screen, always-on viewer for one URL. Reloads the page fresh at up to 4 times a day.

## Get the APK (pick one)

### A) GitHub, no installs (easiest)
1. Create a free GitHub repo and upload this whole folder (keep the `.github` folder).
2. Open the repo's **Actions** tab -> latest "Build APK" run (starts automatically, ~3 min).
3. When green, download **WeatherWall-apk** at the bottom, unzip, install `app-debug.apk`.

### B) Android Studio
Open this folder -> Build > Build APK(s) -> app/build/outputs/apk/debug/app-debug.apk

## Setup on the display device
1. Open the app. Settings appears on first run (later: long-press the screen).
2. Enter URL, tick and set up to four times, tap Save & display.
3. Grant: exact alarms, display over other apps, battery "Unrestricted".
4. Plug the device in permanently.
